How to Protect a Folder in Windows So Nobody Can Open, Move or Delete It

By Akhouri Anmol Kumar · 2026-10-24 · 4 min read

The built-in Windows lock screen protects your session, but it does nothing for your files once someone is sitting at an unlocked PC. ATLOCK File Guard applies protection at the NTFS level, so guarded files cannot be opened, moved or deleted by anyone on that machine.

Before you start

  • Windows 10 or 11, 64-bit.
  • Download the ATLOCK zip and extract it anywhere — there is no installer and no admin rights are needed.
  • Decide which files or folders are sensitive (documents, scans, project folders).

Protect your files

  1. Run ATLOCK.exe and open the File Guard panel.
  2. Add the files or folders you want protected. NTFS-level locking is applied immediately.
  3. Try opening one of the guarded files — it should be refused. That confirms protection is active.
  4. When you need normal access again, remove the guard from the same panel.

Combine File Guard with System Lockdown

For leaving your desk, pair File Guard with System Lockdown. Guarded files stay protected even if someone sits at your unlocked session, and the lockdown timer cannot be bypassed once it starts. Failed unlock attempts are photographed automatically if you have a webcam.

Common questions

Does this upload anything?

No. ATLOCK is fully offline: nothing is uploaded and there is no account or telemetry.

Do I need a webcam?

No. A webcam is only used for intruder photos; File Guard, Lockdown and the Vault work without one.

Will it work on a USB drive?

ATLOCK ships as a single portable .exe, so you can run it from any folder you like.
