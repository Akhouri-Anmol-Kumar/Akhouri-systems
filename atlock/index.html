What ATLOCK does

File Guard — lock folders and files on Windows

Add files or folders and ATLOCK seals them in an encrypted container (chunked AES-256-GCM). Guarded items cannot be opened, moved or deleted by anyone using your PC. For strong protection, give a File Guard item its own password.

Quick Lock

A faster way to protect items without typing a password each time. It is protected by Windows DPAPI and the vault gate, so treat it as convenience protection — use File Guard with a password for sensitive data.

Password Vault — offline and encrypted

Store credentials in a vault encrypted with a key derived from your master password using Argon2id. Nothing syncs to a server. A password-health report flags weak, reused, old and breached passwords.

System Lockdown timer

Start a timed lockdown screen to lock your PC for a set duration — useful for studying, focus and parental control. Ending it early needs your real vault master password.

Two-factor and Windows Hello

Add TOTP authenticator codes, optional FIDO2 hardware keys such as a YubiKey, and Windows Hello (face, fingerprint or PIN) to the vault.

Panic password and decoy vault

A panic password opens a decoy vault instead of your real one and logs the event, so a forced unlock does not reveal your real data.

Security Guard

Quick and full scans, a startup-entry check, optional VirusTotal file lookups using your own free API key, ransomware canary decoy files, and an emergency network-disconnect button.

Intruder log and notifications

Failed unlock attempts are recorded in a notification panel. If you have a webcam, intruder photos are saved to your own Pictures folder.

How to get started

  1. Download the ATLOCK zip from the button on this page and extract it anywhere — Desktop, a folder or a USB drive.
  2. Run ATLOCK.exe. No installer and no admin rights are needed.
  3. Create your vault master password. Choose a long one — forgetting it means the vault stays closed.
  4. Add files or folders in File Guard, store credentials in the Vault, or engage a Lockdown from the home screen.

ATLOCK FAQ

Is ATLOCK free?

Yes. ATLOCK is free to download and use, with no trial period and no account.

How do I lock a folder in Windows 10 or 11 with ATLOCK?

Open the File Guard panel, add the folder, and ATLOCK seals it. For strong protection give the item its own password. You can remove the guard from the same panel.

Is the ATLOCK password vault really offline?

Yes. The vault is encrypted on your device with a key derived from your master password using Argon2id and never leaves your machine. The optional breach check sends only a short hash prefix, and only when you run it.

Can ATLOCK replace BitLocker?

No. ATLOCK is an application-layer tool and does not use a kernel driver. For full-disk protection, BitLocker is the right tool; ATLOCK adds file-level protection, a vault and lockdown on top.

What if I forget the master password?

There is no cloud recovery. A queued reset can complete after 24 hours, but encrypted vault data stays protected, so keep your password safe.

Do I need a webcam?

No. A webcam is only used for intruder photos. File Guard, Lockdown and the Vault work without one.

Why does Windows SmartScreen warn me?

ATLOCK is a new, unsigned indie app. Click More info, then Run anyway. The release page and source are public on GitHub.
