About ATLOCK

🔒System Lockdown

Lock your entire system for a set duration. No bypass. No password override during the lock period.

🛡File Guard

NTFS-level file locking. Protected files cannot be opened, moved or deleted by anyone.

🔑Password Vault

Encrypted local password storage. Your credentials stay offline — no cloud, no leaks.

📸Intruder Log

Automatically captures intruder photos on failed unlock attempts. Know who tried.

⚡Emergency Halve

One-time emergency option to halve your remaining lock time. Use it wisely.

📦Single .exe

No installation. No setup wizard. Drop the .exe and it runs. That's it.

FIELD GUIDE · ATLOCKLock your PC on a timer — full walkthrough
  1. Download ATLOCK.zip from the button above and extract it anywhere — no installer, no admin rights needed.
  2. Launch ATLOCK.exe and set your lock duration on the Lockdown panel.
  3. Confirm your master password. During the lock window there is no bypass and no override — plan accordingly.
  4. Want an escape hatch? Arm the one-time Emergency Halve before you lock, not after.
  5. Add sensitive documents to File Guard so they cannot be opened, moved or deleted while you are away.
  6. Walk away. Any failed unlock attempt is photographed automatically into your Pictures folder.

ATLOCK FAQ

What happens if a System Lockdown is running and I need my PC back early?
Lockdown timers can't be bypassed before they end — that's the whole point of it. Only the one-time Emergency Halve option can cut your remaining time in half.
Where are intruder photos and videos saved?
Straight to your own Pictures/Videos folders on your machine. Nothing is ever uploaded or sent anywhere.
Is my Password Vault actually encrypted?
Yes — the vault is AES-encrypted with a key derived from your master password, and it never leaves your device.
Do I need a webcam for ATLOCK to work?
No. Intruder capture uses a webcam if you have one, but Lockdown, File Guard and the Password Vault all work fine without it.

Field Guides

Practical, step-by-step walkthroughs for the tasks people actually download these apps for. Written by the developer, updated with every release.

GUIDE 01 · SECURITY · 4 MIN READHow to protect a folder so nobody can touch it (ATLOCK File Guard)
  1. Open ATLOCK and go to the File Guard panel.
  2. Add the files or folders you want protected — NTFS-level locking is applied immediately.
  3. While guarded, files cannot be opened, moved or deleted by anyone on that machine.
  4. Combine with System Lockdown when leaving your desk: guarded files stay protected even if someone sits at your unlocked session.
  5. Remove guard from the same panel whenever you need normal access again.
GUIDE 02 · PRIVACY · 3 MIN READKeep an offline encrypted password vault (ATLOCK Vault)
  1. Open the Password Vault panel in ATLOCK and set a master password.
  2. Your vault is AES-encrypted with a key derived from that master password.
  3. Add credentials as usual — everything is stored locally on your device.
  4. There is no cloud sync and no account, so nothing can leak from a server that doesn't exist.
  5. Remember: forgetting the master password means the vault stays closed. That is the point.
GUIDE 03 · PRODUCTIVITY · 3 MIN READReplace Notepad completely: tabs, highlighting and auto save (ANOTE)
  1. Set ANOTE as your default editor for .txt and code files.
  2. Open multiple files — each gets a proper tab, not a workaround window stack.
  3. Code files get language-aware syntax highlighting automatically.
  4. Auto Save runs as you type, so closing the laptop mid-sentence costs you nothing.
  5. For private journals, lock the individual file with its own password.
GUIDE 04 · MEDIA · 4 MIN READShrink and convert images for web upload without quality loss (APIC)
  1. Drag your images (or a whole folder) onto the APIC window.
  2. Choose Convert → WEBP for the best size-to-quality ratio on websites.
  3. Add the Compress operation to cut file size dramatically without visible loss.
  4. Run the batch — progress for all files is shown in one pass.
  5. Verify originals are untouched: APIC editing and conversion are non-destructive unless you choose to overwrite.
