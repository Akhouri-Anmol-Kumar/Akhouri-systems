    // FAQ
    Questions.
    Are these apps really free?
    Yes. Every app is free with no trial period, no locked features and no forced sign-up.
    Do the apps collect my data?
    No. There is no telemetry, no analytics and no cloud account. Everything stays on your machine.
    Windows shows a SmartScreen warning. Is it safe?
    Windows SmartScreen often flags new, independent software it has not seen widely yet. Choose More info, then Run anyway. ATLOCK is also available on the Microsoft Store. Otherwise, download only from this website or our official GitHub releases.
    Which Windows versions are supported?
    Windows 10 and Windows 11, 64-bit. Older versions are not officially tested.
    Is there a web version?
    Yes. APIC Studio runs in your browser at apic-studio.vercel.app. The desktop APIC remains available as a portable Windows app.
    How do I report a bug or suggest a feature?

    Is Akhouri Systems a registered company?
