What APIC does

Edit mode — non-destructive editing

Crop, resize, rotate and adjust brightness, contrast and saturation. Your originals stay untouched unless you choose to overwrite them.

Convert mode — batch image converter

Convert between PNG, JPG, WEBP, BMP, TIFF, ICO and more. Drop a whole folder and convert hundreds of images in a single pass.

Compress mode — shrink file size

Reduce image file size dramatically without visible quality loss, ideal for website uploads, email attachments and storage.

Search mode — find images fast

Search for images across your system by format, size or name instead of digging through folders.

Drag and drop

Drop any image or folder onto the window and APIC works out what to do next.

APIC Web — the browser version

Need it on a phone or a PC that is not yours? APIC Web runs in your browser with editing, conversion, compression, resizing and on-device background removal. No signup required.

How to batch convert images

  1. Download and extract the APIC zip, then run APIC.exe — or open APIC Web in your browser.
  2. Drag your images or a whole folder onto the window.
  3. Open Convert and pick the target format, for example WEBP for websites or JPG for sharing.
  4. Optionally add Compress to shrink the output, then start the batch and check the results.

APIC FAQ

Is APIC free?

Yes, both the Windows app and APIC Web are free to use.

How do I convert PNG to JPG in bulk?

Drop your folder into APIC, choose Convert, pick JPG as the target format and start the batch.

How do I convert images to WEBP?

Use Convert mode and choose WEBP. Add Compress for an even smaller file size.

Does APIC upload my images?

The desktop app does not upload anything. APIC Web is built to process images in your browser.

Can APIC open HEIC or AVIF photos?

Yes. APIC can open HEIC and AVIF along with PNG, JPG, WEBP, BMP, TIFF, GIF and ICO.

Is editing destructive?

No. Edit mode is non-destructive, so originals stay untouched unless you choose to overwrite them.

Do I need to install anything?

No. APIC is a single portable .exe, and APIC Web needs only a modern browser.
